# UPC 2026 B 题 —— 用两个早期球位预测点球入网点

**Team 230** · 2026 年大学物理竞赛 · B 题 · [English](README.md)

题目给出踢球点 $(0,0,0.11)$ m 与 $t=0.05$ s、$t=0.10$ s 两个球心坐标。本仓库
包含论文（LaTeX 源码与编译好的 PDF）、产生论文中每个数字的代码、以及可机读的结果。

## 结论

用六参数横向力模型——初速度 3 个分量、阻力系数 $C_D$、以及垂直于飞行方向的两个
力系数——在我们自己写的阻尼 Gauss–Newton 下按 5 mm 位置噪声拟合六个数，再把后验
推到 $x=11$ m 平面：

| 量 | 值 |
|---|---|
| 入网点 | $y=2.785$ m、$z=1.945$ m、$t=0.399$ s |
| 相对球门 | 距右门柱内侧 0.87 m、横梁下 0.50 m |
| 90 % 区间 | $y\in[2.455,3.121]$ m、$z\in[1.617,2.276]$ m |
| 整球净进球概率 | 0.971 ± 0.001 |
| 模型包络（两个完整模型） | $y\in[2.125,3.121]$ m |
| 情景包络（25 个单因素 + 4 个联合压力） | $y\in[2.259,3.935]$ m |

论文的重点不是小数点后第三位，而是：

- **加速度是二次差分，天然不可靠**：两个定位相隔 0.05 s，5 mm 噪声给出
  $\sigma_a\approx 9$ m s$^{-2}$，与空气动力同量级，所以"弯不弯"只能靠先验与模型约束。
- **决定宽度的是模型形式而非采样**：两条边际 90 % 区间不等于 90 % 联合区域
  （附录 F），模型并集是统计区间的五倍。
- **真实追踪数据无法判定 $C_D$**：对两套 25 Hz 二维数据反解阻力系数，原始数据中位
  0.38（四分位 0.28–0.73），平滑后 0.11，而同一估计器在合成飞行上给出
  0.200→0.209，说明差异来自追踪管线而非足球（§6.8）。
- **题给三个点不是典型自由飞行**：31 m s$^{-1}$ 下它要求 22.6 m s$^{-2}$（2.3g）
  的水平减速，高于真实轨迹的 95 分位。
- **方法可转成观测设计结论**：题目的两个时刻给出 $\sigma_y=211$ mm；把第一次
  放在 0.11 s、第二次放在 0.31 s 则给 12 mm，提升 18 倍。

## 编译

```bash
make          # xelatex + 提交检查
make pdf      # 另存为 230B.pdf
```

依赖 TeX Live（XeLaTeX、booktabs、siunitx、natbib）与 Python 3（numpy、matplotlib、
pymupdf）。读参考 PDF 的作图脚本需要环境变量 `UPC_ROOT`。

## 校验

`code/audit.py` 从原始结果文件重算正文数字；两套积分器（RK4 与 DOP853）一致到
$2\times10^{-6}$ m，两套采样器一致到 3 mm，另一条独立实现的流水线复现答案到 4 cm；
端到端覆盖率由 750 条合成真值测得（500 条五参数模型、50 条六参数模型、25 条含额外
竖直力的错误模型）。

## 数据与许可

空气动力学系数、自转衰减、实测飞行时间与追踪精度均取自论文引用的文献
（Carré 2005；Goff & Carré 2012；Asai 2020；Tsukada & Sakurai 2008；Mehta 1985；
Bassek 2025；Metrica 样例数据）。公开数据集中没有"已知自转、已知入网点"的点球轨迹，
因此端到端检验是合成的，而测量部分是真实的。本仓库的文本、代码与图使用 MIT 许可
（见 `LICENSE`），第三方论文与数据仍遵循各自条款。
